无新增组件需求，可复用现有设计

2026-08-05 授权卡片逻辑对齐结论
- 卡片触达逻辑：谁发起任务，卡片就给谁- ask for user / ask for confirm 统一「对人触达」
- 其他成员不可见

- 授权存储维度- 云资源、视频、编程、邮件等高风险能力 → 用户 + 会话（session）维度
- 本地文件夹/设备权限 → 额外叠加设备维度，且只对当前设备持有者生效

- 多人/多 Agent 场景- 卡片仍只触达发起者，其他人可通过 toolcall 执行痕迹感知状态
- 继续沿用原有排队/打断机制，不额外处理

- Composer 职责边界- 只负责基础授权卡片能力
- 不做统一授权取消入口，取消/白名单由各业务方自行实现
