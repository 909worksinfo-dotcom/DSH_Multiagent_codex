# Agent Note: 主 Agent 协调的协作 Playground

Status: implemented

[English](2026-08-17-collaboration-playground.md) | 中文

## Problem

Harness 已经在普通会话中提供 subagent 和 workflow 编排，但用户启动协作任务时，没有面向任务的界面来说明团队构成、区分讨论与交付物，或保留通往权威协调会话的直接入口。若为该页面增加第二套编排运行时，就会重复 Agent 生命周期、会话持久化、取消和工具权限。

## Decision

`@deepseek-ai/dsh-client-ui-collaboration` 通过现有 Slot 系统贡献根作用域侧边栏操作、独立弹窗和一个 `shell.overlay` 入口。其浏览器持久 store 负责任务卡片和查看状态。创建任务会记录标题、目标和一条协调启动消息；启动真实协作会创建普通 Harness 会话、重命名会话，并发送一条协调提示，要求主 Agent 使用当前装配的 subagent 或 workflow 能力创建任务专属 Agent。主 Agent 从任务推导团队规模、名称、专业能力、职责和提示词，而不套用固定角色组合。每个 Agent 先独立贡献，再接收其他观点并至少进行两轮直接的 Agent 间回应。主 Agent 管理信息传递、参与度和讨论范围，但不提前裁决；只在团队讨论结束后验收，不合格则退回团队继续讨论。

会话日志仍是模型工作的权威来源。任务卡片只保存会话 ID，并轮询现有客户端会话快照。主 Agent 的最终回复使用 `## 任务结果` 和 `## 汇总报告` 两个明确标题；页面从这些章节派生结果和报告页签，并提供直接打开协调会话的入口。

根作用域浮层根据协作标题前缀识别当前协调会话，并在挂载期间打开该会话的子智能体目录。右侧面板以头像列表展示持久化子智能体成员；拖动面板左边缘会更新根作用域 store 中的宽度并持久保存。选择头像后，面板使用目录条目的父会话、子会话和模式地址读取该子会话的全部 `subagents.history` 分页。投影会排除推理块、重复消息、执行流水和不符合任务语言的文本；最新一条助手文本作为最终工作，关键对话最多保留八条并去重。切换选择或卸载会取消过时读取；历史读取受 `historyTimeoutMs` 限制。普通会话不渲染协作浮层。

创建任务时会检测任务名称和目标的主要语言。独立界面、启动消息、协调会话标题、主管理智能体提示词、每个子智能体提示词、智能体间讨论和最终章节均使用该语言。旧任务卡片根据已保存的任务文本推导语言，既有会话根据首条用户消息推导语言。不匹配的旧子智能体文本会隐藏，旧名称则本地化，避免在面板中混用语言。

浏览器 store 刻意不是第二份会话日志。启动消息在模型工作开始前帮助用户理解团队，并明确标注角色活动；真实工具调用、子 Agent 输出、失败和最终文本仍保留在普通会话记录中。

## Alternatives considered

**新增 Host 协作服务和持久事件族。** 不采用，因为当前产品需求没有引入新的执行语义。Session、subagent、workflow 和主 Agent 输出已拥有执行与持久化；另一套服务会重复生命周期控制与存储。

**只增加一个向当前聊天注入提示词的快捷入口。** 不采用，因为它无法提供所需的任务列表、群聊导览，以及独立的结果和报告视图。

**把每个子 Agent 的会话复制进浏览器任务 store。** 不采用，因为这会产生第二个有损权威来源，且无法保留工具调用、取消、重连或回放语义。右侧面板直接从持久化历史读取所选子智能体，不会激活该子智能体。

## Consequences

该功能复用完整 Agent 运行时，不改变 wire 或会话格式。任务卡片能跨浏览器刷新保留且保持轻量，但清除浏览器存储会移除卡片而不会删除 Harness 会话。右侧面板直接使用持久化子智能体目录和历史，因此保留可识别协作标题前缀的既有协作会话也能显示面板；移除该前缀后，面板会隐藏。
