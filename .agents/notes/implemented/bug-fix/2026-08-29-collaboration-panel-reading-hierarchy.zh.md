# Agent Note: 协作面板阅读层级

Status: implemented

[English](2026-08-29-collaboration-panel-reading-hierarchy.md) | 中文

## Problem

多智能体协作主界面会把权威任务描述截断为六十个字符，CSS 还会将它压成单行省略文本，导致验收条件可能从任务清单中消失。右侧面板在页签上方重复展示任务原始 Prompt，而协作协议页面重复展示拓扑标签，并使用了过多嵌套边框和拥挤的固定网格

## Decision

主任务清单只会标准化换行空白，不再修改或截断任务描述，并允许完整文本自然换行。右侧面板在固定顶栏中保留产品名称和实时状态，不再重复渲染任务标题或目标

协作协议仍使用权威运行时投影和原有状态，但调整为三层阅读结构：强制规则与实时限额、成员权限与消息预算、质疑路由。页面继续使用现有设计 Token、单一品牌强调色、响应式自适应网格以及语义化警告和错误颜色，同时减少嵌套边框

## Alternatives considered

**保留六十字摘要，并在悬停时展示全文。** 不采用，因为触屏和键盘用户仍可能遗漏执行要求，任务清单需要保持直接可审计

**用简化静态说明取代协议投影。** 不采用，因为运行时限额、权限和违规状态是实际运行信息，不是装饰性帮助文本

## Consequences

长任务细节会占用更多垂直空间，但内容保持完整且可审计。去除重复 Prompt 后，群聊获得更多可用空间，不会改变任务选择或执行。协议行为和数据契约保持不变，组件测试覆盖完整描述、无 Prompt 右侧面板、唯一拓扑标签和新的语义化协议分组
