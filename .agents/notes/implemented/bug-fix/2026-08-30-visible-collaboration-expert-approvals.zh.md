# Agent Note: 在协作任务中展示阻塞专家的审批

Status: implemented

[English](2026-08-30-visible-collaboration-expert-approvals.md) | 中文

## 问题

协作任务执行期间，专家子会话可能发起工具审批。运行时会正确保持任务执行中并暂停执行超时，但协作面板没有展示由专家会话持有的审批，用户因此只能看到任务似乎卡住，却没有可执行的操作

## 决策

协作客户端现在会直接读取当前任务中每个专家会话的待处理审批，并在协作页签上方展示一条阻塞审批提示。提示会标识专家、工具和原因，并提供拒绝、仅本次允许和当前任务允许，不改变现有权限策略

审批回复严格绑定当前待处理请求的唯一 key。如果 key 已过期或运行时拒绝回执，界面会报错，不会误答复其他请求或假装执行已恢复

扫描以任务 roster 中的专家会话为数据源，会话列表变化只作为刷新信号。即使侧边栏会话摘要的待处理状态延迟或遗漏，审批仍然可见

## 备选方案

**自动批准专家工具。** 不予采用，因为这会绕过用户配置的权限边界

**把审批状态复制到协作领域存储。** 不予采用，因为这会重复短暂的运行时状态并产生过期审批记录

**只检查侧边栏会话摘要。** 不予采用，因为本次故障已证明其待处理投影可能落后于权威的子会话状态

## 影响

需要专家工具审批的协作任务现在会明确进入等待授权状态，并可在用户做出决定后继续。现有任务执行、超时暂停、团队路由和完成门禁保持不变
