Ask for User

任务执行中向用户补充询问或收集确认信息，支持纵向单/多选 + 自由补充，以及横向滑动带图模板卡片两种样式。

- 纵向样式：白色大圆角卡片，带弥散阴影和悬浮感；顶部栏左侧为较大加粗的引导性主问题标题，右侧包含步骤进度（如 < 1 of 3 >，支持左右翻页箭头）、橙色倒计时胶囊和关闭按钮 X；中部为纵向选项列表，每项包含圆形数字编号、加粗选项标题、辅助描述文字，选中或悬停时背景变浅灰并在右侧出现箭头指示符；底部包含铅笔图标 + 自定义反馈入口“否，并告诉 AI 应该如何做”，右下角为“跳过”圆角边框按钮。支持多轮提问翻页（< 1 of 3 >）。
- 横向样式：横向滑动展示带图模板卡片。

 [图片说明：图片展示的是Coze 3.5 Composer工作组件清单中“顶部挂载区”部分的Ask for User界面。界面中显示用户tongyulinalfredbyted请求策划2026世界杯主题html网页，要求Agent在动手前使用ask_user询问3个必要选择。下方是自媒体运营达人AI的回复，询问用户希望网页的视觉风格，提供了赛博朋克/科技未来感、活力运动风、杂志/高端编辑风、极简留白四种风格选项，还设有“其他，请输入...”输入框及“跳过”“提交回答”按钮。]  [图片说明：图片展示的是Coze 3.5 Composer工作组件清单中“页面规模和复杂度？”的问答界面。界面显示当前为第3/3页，用时73秒。有1 - 2屏、核心信息一目了然的精简单页；多板块滚动、内容丰富但一个页面搞定的长滚动单页；顶部导航切换不同板块、像小型站点的分区导航等选项，底部有“跳过”和“提交回答”按钮。该图片与文档中介绍Coze 3.5 Composer工作组件清单的内容相关，是其中问答环节的呈现。]  [图片说明：图片展示了Coze 3.5 Composer工作组件清单中顶部挂载区的示例。上方是自媒体运营达人AI的回复，称收到，将走极简留白+综合信息站+长滚动单页的路线，干净克制，高级感拉满。下方是tongyulinalfredbyted的回复，其选择的网页视觉风格为杂志/高端编辑风，页面主要展示综合信息站，页面规模和复杂度为精简单页。该图片直观呈现了顶部挂载区的交互样式及用户选择内容。]  [图片说明：这张图片展示了Agent执行敏感操作时触发的授权卡片，呈现为白色大圆角卡片样式，细边框搭配轻微投影。卡片上列出网页用途的选项，包括赛事信息站、倒计时互动、球迷应援主页、数据可视化，还有其他输入项，底部设有「跳过」和「提交回答」按钮。卡片明确显示为第1页共3页，标注了耗时104秒，完成处理后提示选完提交，符合文档中所述的Composer阻断层授权卡片的相关描述，用于用户确认操作权限。]

授权卡片（Permission Card）

Agent 执行敏感操作前触发，阻断式展示，用户可选「允许一次」/「允许此对话」/「拒绝」；链路与 Ask for User 一致，卡片样式参见 PRD。

区域同 Ask for User（Composer 阻断层）；白色大圆角卡片 + 细边框 + 轻微投影，按权限类别展示语义化图标、问句标题、灰色说明或代码块；底部为「拒绝」+「允许一次」组合按钮，箭头上弹菜单支持「允许一次」/「允许此对话」。
