DEFINITION & BOUNDARY

RSI 不是持续学习、AutoML 或普通 Agent

03

系统利用自身产出，改进产生下一次改进的机制；改进后的系统再重复该过程。

RSI = self-reference + closed-loop evaluation + retained change + repeated iteration

相邻概念是否 RSI边界
Continual Learning部分吸收新数据不等于改进学习机制
AutoML / NAS部分外部固定搜索器通常不是自我改进
Self-training条件成立需形成可持续、可保留的能力闭环
Agent reflection通常否一次性反思但不改变未来系统
Self-modifying agent强相关改变可执行策略且经验证保留
AGI / ASI不等价能力水平与改进机制是两条轴

07

原理

优点

投资入口

代表方案

AlphaDev、FunSearch、AlphaEvolve、Darwin Gödel Machine、SICA 类 self-improving coding agents。

为何进展快

程序可编译、可测试、可 benchmark；反馈密度远高于开放式自然语言任务。

边界

“在 benchmark 上更快”不等于跨任务智能提升；安全审计与供应链风险不可省。

ROUTE 6

训练配方与架构 AutoML：最接近“改进学习器”

12
OUTER

元优化器提出 optimizer、data mixture、curriculum、architecture 与 loss 变体。

INNER

训练候选模型，以验证损失、能力、成本和安全指标回传。

潜力

直接改变“如何学习”，理论递归深度高；可能发现人类未设计的训练算法。

现实约束

每个候选都可能需要大规模训练；实验并行昂贵，噪声与复现困难。

代表脉络

Neural Architecture Search、Population Based Training、learned optimizers、自动 curriculum。

投资判断

更可能被前沿实验室内化；外部机会在低成本代理评测与训练基础设施。

理论吸引力：最接近 open-ended evolution。工程风险：目标难以形式化，生态内胜出不等于现实价值；欺骗性策略更难发现。

Evaluator hacking

系统优化评测代理而非真实目标；越多轮递归，偏差累积越快。

Credit assignment

长链任务失败难以归因到 prompt、memory、tool 或模型哪个变化。

Information ceiling

纯自生成闭环不引入外部信息时，容易重组已有模式而非创造新知识。

Distribution shift

在固定 benchmark 提升，不保证真实世界与下一代任务提升。

THEORETICAL BARRIERS

单调提升、分布外泛化与收益递减均无保证

16

一 · 非单调性

局部改进可能破坏其他能力；多目标性能没有天然全序关系。

catastrophic regression

二 · 自参照限制

系统无法轻易证明比自身更强的修改在所有未来情境下安全有效。

verification gap

三 · 边际递减

早期“低垂果实”被采完后，搜索空间扩大、每次净提升趋小。

diminishing returns

现实 RSI 更可能是阶梯式、带回退、受预算约束，而不是指数爆炸的平滑曲线。

ENGINEERING CHALLENGES

反馈回路会放大评测污染与基础设施脆弱性

17

评测污染

训练与隐藏测试边界失守，系统学会题库而非能力。

版本漂移

模型、工具、依赖同时变化，难以重现实验与定位退化。

沙箱逃逸

自改写代码需要更强权限，扩大供应链与执行风险。

成本失控

候选×评测×重试形成乘法，单位改进成本快速上升。

必须具备

不可变日志、数据血缘、权限隔离、隐藏回归集、可回滚 artifact

CONTROL PLANE
不应依赖

单一 LLM-as-a-Judge、公开 benchmark、无上限 token budget

ANTI-PATTERN
商业机会

EvaluationOps、agent observability、secure sandbox、trajectory warehouse

Darwin Gödel Machine：以开放式演化改写 Coding Agent

18
MAY 2025 · ARXIV:2505.22954

Darwin Gödel Machine

Sakana AI · University of British Columbia

https://arxiv.org/abs/2505.22954

让 agent 读取并修改自己的代码，以 archive 保存多样候选，再用 coding benchmark 选择后代。

核心思路

Darwinian search + self-referential code modification；不是单一路径爬山，而是保留质量与多样性。

创新点

将 Gödel Machine 的自修改愿景转化为可运行的开放式工程循环，并报告跨模型/任务改进。

RSI 含义：展示 L3 级“系统代码自改写”证据；但依赖外部 benchmark、基础模型与人工定义的适应度，尚非自主 L4/L5。

MAY 2025 · GOOGLE DEEPMIND

AlphaEvolve

Google DeepMind

A Self-Improving Coding Agent：Agent 直接编辑自身系统

20
APR 2025 · ARXIV:2504.15228

A Self-Improving Coding Agent

University of Bristol · Microsoft Research

https://arxiv.org/abs/2504.15228

赋予 Agent 基础编码工具，使其通过反思、代码改写和基准反馈自主编辑自身 Agent 系统，无需梯度更新。

红旗
